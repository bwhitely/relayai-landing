Chat Widget Demo

This page demonstrates the embeddable chat widget. Look for the chat bubble in the bottom-right corner.

Try these messages to test tool use:
  • "Can you echo hello for me?" — triggers the echo tool
  • "I'd like to speak to someone about a billing issue" — triggers escalation
  • "My name is Sarah Jones, phone 0412345678, email sarah@test.com" — triggers create_lead

The widget is configured to connect to the local agent service. Make sure uvicorn is running on port 8000.
